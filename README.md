# 🚀 TaskFlow DevOps

Proyecto para aprender GitHub, DevOps y trabajo en equipo.

---

## 🎯 Objetivo
Construir un sistema de tareas en Python usando flujo DevOps real.

---

## 🔁 Flujo obligatorio

1. Clonar repositorio
2. Crear branch
3. Resolver tarea
4. Commit claro
5. Push
6. Pull Request
7. Revisión
8. Merge a main

---

## 🧩 Funciones

- Agregar tareas
- Listar tareas
- Completar tareas
- Eliminar tareas
- Guardado automático en JSON

---

## ⚠️ Reglas

- NO trabajar directo en main
- Todo es por Pull Request
